PART 1

Internet Technologies Explained

Exploring the foundational infrastructure, network protocols, browsers, and search engines that power the global World Wide Web.

🌐
Topic 01

How the Internet Works

The Internet is a global, decentralized network of interconnected computers communicating via standardized rules known as the TCP/IP protocol suite (Transmission Control Protocol / Internet Protocol). When you request a webpage, your computer splits data into tiny packets of digital information.

These packets travel across physical fiber-optic undersea cables, wireless towers, and network routers. Each device on the network is identified by a unique IP Address (such as IPv4 192.0.2.1 or IPv6 2001:db8::1). The Domain Name System (DNS) acts as the phonebook of the Internet, translating human-friendly web addresses like example.com into machine-readable IP addresses.

  • Packet Switching: Breaks large files into small packets that take optimal network paths and reassemble at the destination.
  • Client-Server Architecture: Your browser (client) sends HTTP/HTTPS requests to remote servers, which send back web content.
  • TCP/IP Handshake: Establishes a reliable, encrypted connection ensuring data packets arrive complete and uncorrupted.
📡
Topic 02

Internet Service Providers (ISPs)

An Internet Service Provider (ISP) is an organization that provides individuals, schools, and businesses with access to the global Internet. ISPs form a hierarchical network structure operating across three main tiers:

  • Tier 1 ISPs: Global telecommunication backbones (such as AT&T, Verizon, and Lumen) that own vast transcontinental fiber-optic cables and route data without paying transit fees.
  • Tier 2 ISPs: Regional providers that purchase access from Tier 1 backbones to connect cities and large geographical regions.
  • Tier 3 ISPs: Local consumer providers (cable, fiber-to-the-home, 5G cellular) that deliver internet directly to homes and schools.

Your ISP provides your router with an external IP address, manages bandwidth speeds, resolves initial DNS lookups, and routes your outbound web traffic onto the global internet backbone.

💻
Topic 03

Web Browsers

A Web Browser (such as Google Chrome, Mozilla Firefox, Apple Safari, or Microsoft Edge) is a client-side software application that retrieves, parses, renders, and displays web pages from internet servers.

When a web browser receives HTML, CSS, and JavaScript files from a web server, its internal rendering engine performs a multi-stage pipeline:

  1. HTML Parsing & DOM Construction: Converts HTML tags into a hierarchical Document Object Model (DOM) tree structure.
  2. CSS Parsing & CSSOM: Processes CSS stylesheets into the CSS Object Model (CSSOM) tree to compute visual styles.
  3. Render Tree & Layout: Combines DOM and CSSOM to compute exact pixel coordinates and layout geometry on screen.
  4. Painting & JS Execution: Draws visual pixels to screen while the JavaScript engine (e.g. V8 engine) executes dynamic client code.
🔍
Topic 04

Search Engines

A Search Engine (such as Google Search, Bing, or DuckDuckGo) is a specialized software system designed to discover, index, rank, and retrieve information across billions of web pages on the World Wide Web.

Search engines operate continuously through three core processes:

  • Web Crawling: Automated bots (known as spiders or crawlers) follow hyperlinks across the web to discover new and updated content.
  • Indexing: Extracted text, metadata, images, and links are cataloged into a massive, searchable reverse-index database.
  • Ranking Algorithms & AI: Sophisticated algorithms evaluate hundreds of factors (keyword relevance, backlink authority, user intent, page load speed, and semantic AI embeddings) to return accurate results within milliseconds.
